# Instruksi untuk agent AI

Repo ini berisi website Arenka Logistics dalam satu file: `index.html` (HTML, CSS dan JavaScript inline,
ilustrasi SVG inline). Baca `README.md` dulu.

## Aturan dari pemilik (Restu)

- **Jangan merombak desain.** Struktur, urutan section, layout, interaksi dan warna versi ini adalah dasar yang
  dipilih pemilik. Ubah hanya bagian yang diminta. Perombakan total pernah ditolak dan dikembalikan ke versi ini.
- **Tugas berikutnya:** perbaiki bagian yang terlihat "AI slop" saja, dengan tetap mempertahankan desain ini.
  Tunjukkan dulu daftar bagian yang mau diubah sebelum mengubah banyak hal.
- Warna merek tetap: Heritage Blue `#002e62` dan Lime `#d0f600` (token di `:root`).

## Batas isi

- Jangan menyalin teks, foto, angka, testimoni atau kontak milik lomiles.com. Situs referensi hanya untuk struktur.
- Jangan mengarang angka, testimoni, alamat atau nomor kontak. Data asli diisi lewat objek `ARENKA`
  di bagian bawah `index.html`; selama kosong, halaman menampilkan penanda bergaris putus-putus.

## Cara cek setelah mengubah

- Buka `index.html` di lebar 1440 px dan 390 px: tidak ada scroll ke samping, tidak ada error di console.
- Cek interaksi: dropdown navigasi, menu mobile, tab Cara kerja, carousel testimoni, formulir kontak,
  dialog bantuan, tombol "Jeda animasi".
